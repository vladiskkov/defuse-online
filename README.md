# Дефуз — тактична настолка в стилі CS2

Браузерна покрокова настолка в тематиці CS2: дві команди, закупівля, гранати, бомба. Механіки взято з класичних тактичних настолок — Kill Team, Space Hulk, XCOM. Матчі 1×1, 2×2 або 3×3 з друзями чи ботами, вхід через Google.

## Як грати

Поле — 3D-карта «Дюна», вкрита гексами, тож відстань однакова в усіх напрямках.

- **Мета:** T закладають бомбу на A або B, CT не дають або розміновують. Раунд — 8 ходів (1:55), бомба вибухає в кінці 3-го ходу після закладки.
- **Черговість (Kill Team):** бійці ходять по одному, T і CT по черзі; у непарних ходах першими йдуть T. Активація — 2 дії: рух до 4 гексів, постріл (раз за активацію), граната, закладка (2 дії), розмінування (2 дії, з набором 1).
- **Тримати кут (Space Hulk):** боєць завершує активацію й стріляє першим у ворога, що з'явиться в полі зору (+1 до потрібного кидка).
- **Постріл (Kill Team / XCOM):** атакуючий кидає кубики зброї (Glock/USP — 3, AK/M4 — 4). Влучання на 4+ (M4 — 3+), шістка — хедшот. Штрафи: далеко, стріляв після руху, засліплений. Ціль кидає 3 кубики захисту: блок на 5+, у бронежилеті на 4+, шістка — критичний блок. Укриття поруч із боку стрільця дає ще один автоматичний блок.
- **Туман війни:** ворогів за стінами не видно, лише «?» там, де чути кроки.
- **Закупівля:** AK-47, M4A1-S, броня, шолом, набір сапера, гранати (флешка, дим, осколкова, коктейль). Економіка як у CS2.

## Технології

Node.js 20+, Express, Socket.IO, Three.js, Google Identity Services. Без бази даних і без збірки фронтенду. Сервер вирішує все: позиції ворогів поза полем зору не потрапляють у браузер.

```
shared/   карта, правила, геометрія (спільні для сервера і браузера)
server/   вхід, кімнати, рушій матчу, боти
public/   клієнт: лобі, 3D-карта (world3d.js), інтерфейс ходу
test/     симуляція матчів ботів
```

## Запуск локально

```bash
npm install
GOOGLE_CLIENT_ID=... npm run dev   # без Client ID працює гостьовий вхід
npm test                           # 60 матчів ботів
```

## Деплой

`render.yaml` — Blueprint для Render: **New → Blueprint**, обрати репозиторій. Адресу сайту треба додати в Google Cloud у **Authorized JavaScript origins**.
