# Дефуз — тактика на кубиках

Браузерна покрокова гра в дусі командних шутерів: дві команди, закупівля, гранати, бомба — а кожен постріл вирішує кидок d20. Матчі 1×1, 2×2 або 3×3 з друзями чи ботами, вхід через Google.

## Як грати

Настільна гра в стилі CS2 на 3D-карті «Дюна».

- **Мета:** T заносять бомбу на А або Б і закладають, CT не дають або розміновують. Раунд — 12 ходів (1:55), бомба вибухає через 4 ходи.
- **Зони:** Спавн T, Ворота, Лонг, Точка А, Кет, Мід, Двері міду, Спавн CT, Двері Б, Точка Б, Тунелі Б, Нижні тунелі. За хід фішка переходить у сусідню зону.
- **Хід:** усі одночасно обирають — перейти, ✋ тримати позицію (+1 у бою), кинути гранату, закласти чи розмінувати. Ворогів видно лише у своїй зоні, із сусідніх чути кроки.
- **Перестрілка:** вороги в одній зоні кидають кубики d6 (пістолет — 1, AK/M4 — 2, M4 ще +1). Більша сума влучає (−1 ❤ із 3), нічия — обидва. Хедшот (дубль з AK/M4, шістка з пістолета) вбиває одразу; шолом рятує від хедшота з пістолета й M4. Відступ — 1 кубик: 4–6 чисто, 1–3 −1 ❤.
- **Закупівля:** AK-47, M4A1-S, броня, шолом, набір сапера, гранати-картки (флешка, дим, осколкова, коктейль). Економіка як у CS2.

## Технології

Node.js 20+, Express, Socket.IO, Three.js, Google Identity Services. Без бази даних і без збірки фронтенду. Сервер вирішує все: позиції ворогів поза полем зору не потрапляють у браузер.

```
shared/   карта, правила, геометрія (спільні для сервера і браузера)
server/   вхід, кімнати, рушій матчу, боти
public/   клієнт: лобі, 3D-карта (world3d.js), планування, повтор ходу
test/     симуляція матчів ботів
```

## Запуск локально

```bash
npm install
GOOGLE_CLIENT_ID=... npm run dev   # без Client ID працює гостьовий вхід
npm test                           # 60 матчів ботів
```

## Деплой

`render.yaml` — Blueprint для Render: **New → Blueprint**, обрати репозиторій. Адресу сайту треба додати в Google Cloud у **Authorized JavaScript origins**.
