# Дефуз — тактика на кубиках

Браузерна покрокова гра в дусі командних шутерів: дві команди, закупівля, гранати, бомба — а кожен постріл вирішує кидок d20. Матчі 1×1, 2×2 або 3×3 з друзями чи ботами, вхід через Google.

## Як грати

- **Мета як у CS2:** T заносять бомбу на А або Б, CT захищають і розміновують. Раунд триває 1:55, бомба вибухає через 40 с, розмінування 10 с (з набором 5 с).
- **Хід руху (10 с ігрового часу).** Усі ходять одночасно. Кнопки «Йти на А/Б» прокладають маршрут самі, або можна торкнутися карти. Бігом — 6 клітинок, вороги чують кроки 👣. Тихо — 3. Стояти — тримати кут (+2 у першому обміні).
- **Контакт.** Щойно гравці бачать одне одного, вони зупиняються і починається дуель.
- **Дуель (5 с на обмін).** Кожен учасник обирає дію і сам кидає кубики:
  - стріляти — d20 на кожну кулю черги (AK/M4 — 3 кулі, пістолети — 2); від 10 після бонусів — влучання, 20 або +10 зверху — хедшот; кожна наступна куля −2;
  - сховатися — d20 ≥ 8: по тобі −8, інакше −3, і відскок на 2 клітинки;
  - граната — d20 ≥ 8: лягає точно, інакше відлітає на клітинку;
  - розміновувати — без кидка, 5 с прогресу.
  Постріли одночасні, тож можливі розміни.
- **Шкода як у CS2:** AK-47 36, M4A1-S 38, Glock 30, USP 35; у голову ×4; броня зменшує шкоду.
- **Радар, туман війни, сліди** і підказки для новачків.

## Технології

Node.js 20+, Express, Socket.IO, Three.js, Google Identity Services. Без бази даних і без збірки фронтенду. Сервер вирішує все: позиції ворогів поза полем зору не потрапляють у браузер.

```
shared/   карта, правила, геометрія (спільні для сервера і браузера)
server/   вхід, кімнати, рушій матчу, боти
public/   клієнт: лобі, 3D-карта (world3d.js), планування, повтор ходу
test/     симуляція матчів ботів
```

## Запуск локально

```bash
npm install
GOOGLE_CLIENT_ID=... npm run dev   # без Client ID працює гостьовий вхід
npm test                           # 60 матчів ботів
```
