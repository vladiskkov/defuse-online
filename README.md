# Дефуз — тактика на кубиках

Браузерна покрокова гра в дусі командних шутерів: дві команди, закупівля, гранати, бомба — а кожен постріл вирішує кидок d20. Матчі 1×1, 2×2 або 3×3 з друзями чи ботами, вхід через Google.

## Як грати

- **3D-карта «Дюна»** на Three.js з процедурними текстурами (пісковик, плити, бруківка, дерев'яні ящики), тінями від сонця, димом і вогнем. Камеру можна крутити, наближати і перемикати на вид згори. Логіка — сітка 36×28: точки А і Б, мід, кет, лонг, тунелі. T закладають бомбу, CT захищають і розміновують.
- **Одночасні ходи.** Усі таємно планують хід (40 с), потім рухи розігруються разом — по клітинці за такт.
- **Режими руху:** біг (4 кл., гучно, −2 до кидка), крок (2 кл., тихо), тримати кут (стоїш і стріляєш першим, коли ворог з'являється, +2), ухилення (рухаєшся крізь контакт, по тобі −4, сам −3).
- **Постріл:** d20 + влучність ≥ 11 + дистанція + укриття (+3 за ящиком) + рух цілі. 20 — хедшот, 1 — промах. Шкода — кубики зброї, броня її зменшує.
- **Зброя (концепт):** Glock-18 / USP-S за замовчуванням, AK-47 для T, M4A1-S для CT.
- **Гранати** летять на початку ходу: дим (3 ходи), флешка (−8 до кидків), осколкова, коктейль (вогонь 2 ходи). Кидок забирає 1 крок.
- **Бомба:** закладка — хід на точці, вибух через 7 ходів. Розмінування — 2 ходи, з набором сапера — 1.
- **Туман війни:** ворогів видно лише в полі зору команди; біг видає кроки 👣.
- **Економіка як у CS2:** $800 на старті, нагороди за перемогу, вбивства, бонус за поразки поспіль. До 7 перемог, зміна сторін після 6-го раунду.

## Технології

Node.js 20+, Express, Socket.IO, Three.js, Google Identity Services. Без бази даних і без збірки фронтенду. Сервер вирішує все: позиції ворогів поза полем зору не потрапляють у браузер.

```
shared/   карта, правила, геометрія (спільні для сервера і браузера)
server/   вхід, кімнати, рушій матчу, боти
public/   клієнт: лобі, 3D-карта (world3d.js), планування, повтор ходу
test/     симуляція матчів ботів
```

## Запуск локально

```bash
npm install
GOOGLE_CLIENT_ID=... npm run dev   # без Client ID працює гостьовий вхід
npm test                           # 60 матчів ботів
```
